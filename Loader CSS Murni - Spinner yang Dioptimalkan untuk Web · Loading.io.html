Cara Penggunaan

  • Klik loader yang Anda inginkan
  • Salin CSS ke file CSS Anda
  • Salin kode HTML ke tempat yang Anda butuhkan.
  • Selesai

Kesesuaian

Spinner CSS Loading.io menggunakan Animasi CSS, yang didukung secara luas oleh semua browser modern seperti Google Chrome dan Mozilla Firefox. Namun, Microsoft Internet Explorer versi sebelum 10 tidak mendukung Animasi CSS.

Untuk mendukung IE versi lama, Anda harus menggunakan gambar format GIF. Pilih salah satu dari galeri spinner online loading.io dan Anda dapat menyesuaikan GIF loader unik dengan mudah menggunakan editor ikon kami.

Beberapa browser lama memerlukan awalan seperti '-webkit-' untuk menggunakan Animasi CSS. Untuk meminimalkan ukuran file, kami menghilangkan semua awalan vendor di CSS loader, tetapi Anda dapat menyesuaikan ini dengan membuat CSS dari kode sumber. Lihat README.md di repositori untuk informasi lebih lanjut.
